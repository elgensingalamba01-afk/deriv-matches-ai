Is it actually random?

Pulls Deriv's synthetic-index tick digits and runs the statistical tests that would catch a real pattern — instead of assuming one exists.

Before you trust any number below: this is a statistics instrument, not a betting signal. Deriv's synthetic indices run on a random-number generator, so the honest result is usually "no pattern found" — that's a working test doing its job, not a failed one.

Why can't a predictor just work here?

Each tick's last digit is close to an independent, uniform draw from 0–9. Because it doesn't depend on the digits before it, there's no historical pattern to learn from — the same reason no system beats roulette long-term. Every strategy below is backtested and scored against exactly that fact, so if one clears a "possible edge" bar, treat it as a lead to re-test on fresh data, not as proof.
